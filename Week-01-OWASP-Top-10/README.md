# Week 1 — OWASP Top 10 Vulnerability Research

## Overview

This project was completed as part of Week 1 of the Vortex Tech Cyber Security Internship 2026.

The objective of this assignment was to build a strong theoretical foundation in web application security by researching and documenting five vulnerabilities from the OWASP Top 10.

This research focuses on understanding each vulnerability from both an attacker and defender perspective.

## Objectives

- Understand the OWASP Top 10 web application security risks
- Research five vulnerabilities from the current OWASP Top 10
- Explain each vulnerability in beginner-friendly language
- Understand how attackers may exploit each vulnerability
- Study real-world security incidents related to the vulnerabilities
- Identify practical prevention and mitigation techniques
- Develop structured cybersecurity research and technical documentation skills

## Vulnerabilities Covered

The following five OWASP Top 10:2025 categories were selected for this research:

1. **A01:2025 — Broken Access Control**
2. **A02:2025 — Security Misconfiguration**
3. **A04:2025 — Cryptographic Failures**
4. **A05:2025 — Injection**
5. **A07:2025 — Authentication Failures**

## Research Methodology

For each vulnerability, the research covers:

- What the vulnerability is
- How an attacker could exploit it
- A real-world example or security incident
- Practical prevention and mitigation techniques

The research began with the official OWASP documentation and was supplemented with reliable security resources and documented case studies.
